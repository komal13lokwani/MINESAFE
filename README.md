# MINESAFE

## Smart Mining Safety Monitoring System

MINESAFE is a smart mining safety monitoring system designed to monitor
and improve safety conditions in mining environments.

## Features

- Real-time safety monitoring
- Backend processing
- Interactive frontend interface
- Data analysis and visualization

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Requests
- PyDeck
